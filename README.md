# Developer Portfolio

A personal developer portfolio website built using HTML5 and CSS3.

The website showcases my background, skills, projects, and contact information.

## Pages

- Home
- About
- Skills
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Features

- Clean and professional user interface
- Multi-page website
- Responsive design
- Active navigation indicators
- Project showcase
- Skills section
- Contact information
- Mobile-friendly layout

## Project Structure

```text
developer-portfolio/
├── index.html
├── about.html
├── skills.html
├── projects.html
├── contact.html
├── css/
│   └── style.css
├── images/
└── README.md
```

## Run Locally

Clone the repository:

```bash
git clone https://github.com/amarpatil2408/developer-portfolio.git
```

Open the project folder:

```bash
cd developer-portfolio
```

Then open `index.html` in your browser.
